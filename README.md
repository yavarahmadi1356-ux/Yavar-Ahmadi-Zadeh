# Yavar Ahmadi Zadeh — Live Two-Layer Executive Portfolio

**Industrial Digital Transformation Engineer · AI-Augmented Software Development**

React + Vite + TypeScript application. All editable content lives in `src/data/content.ts`.

## Layers

| Layer | Route     | Contents |
|-------|-----------|----------|
| 1     | `/`       | Positioning, capability framework, industrial expertise, leadership, selected work, career facts, contact |
| 2     | `/profile`| Biography, career journey, asset classes, operational experience, skills, stack, credentials, philosophy, CV |

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Content rules

- Edit only `src/data/content.ts`.
- Do not invent achievements, employers, projects, certifications, or statistics.
- Bracketed fields and `status: "pending"` are unpublished until verified.
- English and Persian (`fa`) are first-class; empty `fa` falls back to English.
